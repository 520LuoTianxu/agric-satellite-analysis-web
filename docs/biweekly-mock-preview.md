# 种植双周报 Mock 原型（页签与内联版）

## 入口与部署

- 基于 master 合并 PR15 后的 `e6d9aa6`；本次分支 `feat/biweekly-inline-phases`，替换旧卡片+宽弹层方案。
- 正常入口：登录后进入地块详情，选择与「地块分析」**平级**的「种植双周报」。原有长势分析默认页签、气象、土壤、预警、地块分析及其分区不变；支持 `?fieldId=原地块ID&tab=biweekly`。
- 独立虚拟预览 `/biweekly-demo`、`/en/biweekly-demo`、`/es/biweekly-demo` 使用同一个内联组件，不伪造真实地块或认证环境。此路由展示宽度最多640px，可缩窄窗口检查侧栏布局。
- Node24，`npm ci`；`npm run dev -- --port 3214`。测试环境静态导出 `npm run build:test` 后按既有流程发布 `out/`。本任务不部署。
- 项目配置 basePath 时需加此前缀，本次 build:test 产物前缀为 `/agric-satellite-analysis-web`。例如 `http://localhost:3214/agric-satellite-analysis-web/biweekly-demo/`；部署时以构建配置为准。
- 全局 AuthProvider / OrgAccessGuard 原样保留；空浏览器可看纯虚拟预览，但已有禁止组织标记仍会拦截，不提供绕过。

## 展示与交互

1. S1 营养生长 → S2 营养/生殖并进 → S3 生殖生长，是农艺监测阶段，**不是 Sentinel 传感器**。
2. 每个阶段列出作物对应生育期，报告仅在其主归属生育期下列出。默认展开模拟当前S2与所选生育期，S3未来空状态也展开；S1可展开追溯。报告列表/折叠区不是二级页签。
3. 冬小麦/玉米各4期、共8份确定性报告。S2拔节期/穗期有两期报告可选，切换后正文直接在树下更新。阅读正文无弹层、抽屉、Portal、焦点锁或内嵌滚动容器。
4. 第2期跨生育期：按**报告起始日**归档，列出覆盖的两个生育期，不重复生成或在不同阶段复制同份报告。日期采用 `[start,end)`：结束日不含；正文观测最后一天为结束日前一天。
5. 未生成/未来生育期保留为清楚的空状态，无伪生成按钮。正文复用长势、跨期解读、FVC/NDVI/LAI趋势与像元示意、历史/周边比较、历史天气、旱涝证据与方法附录。
6. 真实地块侧栏仍为原有288–640px可拖动宽度，页签单行可横滚；报告使用单列卡片、小屏指标降为单列。原型内容有意中文优先，zh/en/es页签有对应资源key，其他locale可构建。

## 数据边界

全部报告、种植季、时间、面积、图形与气象均为虚构。当前模拟进度固定在2027种植季S2，不读取当前真实地块id/作物/方案。FVC / LAI为未验证概念值，PSRI未启用；不把模拟值当正式计算能力。没有新增报告API、生成调用、后台任务、数据库或认证改动。现有全局会话逻辑/业务页地图仍可能联网，不承诺全站零网络。
