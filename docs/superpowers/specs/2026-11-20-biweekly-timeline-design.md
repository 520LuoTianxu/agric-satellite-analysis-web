# 扁平时间轴与Mock PDF（用户t30–32指示）

以最新明确指示为已批准设计，不再重复请求相同布局审批。取代嵌套卡片/手风琴，保留「种植双周报」一级页签。

- 一个浅白横向模块：标题/作物、上一/下一份报告与日期；绿色S1、青色S2、琥珀色S3连续色带；下一行对应具体生育期、月份尺和报告记录圆点。所有坐标按同一个UTC日期尺度同比例定位，S标签是农艺阶段，圆点是报告而非卫星观测。
- 圆点按报告起始日定位，跨期记录按起始日唯一归属并注明覆盖生育期；点击生育期选择其最新报告，无报告时清空正文并显示空状态。选中游标跨越轴行。导航到报告将同步生育期，不让筛选残留；两端禁用、无循环。
- 窄侧栏只让时间轴横滚，标签使用短名/日期、完整可访问名称；选中点仅在时间轴内部滚动居中。不让页面整体横溢出。独立预览扩大到全宽，报告正文保持易读行宽。
- 网页为简明原始指标/趋势/天气/证据与方法，使用章节分隔线而非盒中盒。保留作物、NDVI/FVC/LAI切换。
- 详细PDF是真实静态可下载文件：8份固定Mock快照离线生成中文PDF并提交，非打印对话框、非假生成按钮。预置解读不是实际AI输出，模型版本none。网页和PDF的事实来自同一fixture，manifest含快照和文件SHA256，测试防止漂移。渲染脚本仅是可选开发工具，不新增前端运行依赖。
- API/AI/后端均不接入。未来异步PDF状态契约仅声明queued/running/ready/failed，不模拟真实队列。后台另阶段写离线逻辑，直到用户明确「对接」前端始终使用Mock。生产迁移与部署另行确认。

后续后台：不可变快照→质量受控结构化证据→AI结构化文案（schema校验、数字白名单、证据引用、缺失限制）→PDF产物→下载。记录snapshot/model/prompt/template/policy版本与输入证据指纹。不能选择付费模型、假定FVC校准或LAI模型；重要缺口询问用户。

验收：比例/边界/月份/报告位置/唯一归属/空选择/前后导航、顶级页签保留、无树/弹层、PDF文件与快照一致性测试；完整typecheck/lint/build:test。父代理进行视觉与交互验收。
