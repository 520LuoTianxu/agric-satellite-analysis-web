# T5 双周报紧凑阶段导航修订（t34批准范围）

问题：PR17按全季时长展开长轴，阶段/生育期/圆点多层高行及反复说明挤压报告；900px仍需横滚，窄侧栏更差。本轮实质替换其导航模型，不只是缩放旧轴。

采用已明确认可的方案：面板内等宽、淡色、约36px的S1营养生长/S2并进阶段/S3生殖生长三段始终可见；明确标注「阶段导航·非等比」，不冒充全季比例时间轴。当前阶段下展示完整生育期名称、简短日期和报告数量；紧凑按钮自然换行，未来空期仍可选择。阶段切换选该阶段最新有报生育期，否则第一空期；重复点击当前阶段不重置所选报告。默认仍冬小麦拔节期第04期。

只对当前生育期提供一个报告日期select与前/后报告按钮（不跨期跳转）；正文原位更新、跨期只显示主归属一次。移除全季轨道、月份尺、游标、所有绝对定位与ResizeObserver/scrollTo居中逻辑。相比缩短但仍横滚的全季轴，此方案不会把阶段藏到屏外；相比再次用折叠卡片，没有套娃/二级tab栏。

统一12px主体、16px标题、8–12px垂直节奏。保留一个顶层MOCK标记及简短免责声明；PDF行压缩为产物摘要/下载，原始数据页去冗余标题与大间距，趋势/像元保留但不扩成高空白带。阶段仅轻底色/选中细线，生育期为轻量文本按钮，无嵌套卡片。所有grid/flex子元素min-width:0；不设大最小宽度、不藏溢出来假装适配。

真实平级种植双周报页签、原有默认页签、鉴权、locale资源、固定fixture和8份真实Mock PDF不改。无API/AI/后端改动；T6工作区完全不碰。

验证：纯函数覆盖阶段/生育期/报告过滤、空状态、无重复归属和日期边界；结构/CSS约束覆盖移除长轴、可折行和无弹层。独立Demo增加288/400/640/900px宽度控制及真实DOM溢出读数，便于主代理computerUse视觉验收；不是生产控件，也不以静态测试冒充浏览器截图QA。全量现有Node测试、type-check/lint/build:test、diff检查。

## t35补充：复用项目控件（同一修订）

作物/报告选择改用现有`ui/select`（Radix Select），按钮/下载/指标/演示宽度控制复用`ui/button`，图标导航提示用`ui/tooltip`。不引入组件库、不写原生select或自造dropdown。SelectContent按trigger宽度、viewport可用高度限制、collisionPadding防越界；选项允许日期换行。阶段/生育期仍是专门的轻量Button导航，不套Card。保留共享组件的键盘/选中/禁用/focus行为；弹出选择菜单不等于报告阅读弹层。
