# ADR 0002：新手引导采用可恢复的步骤状态机

- 状态：已采用
- 日期：2026-09-17

## 背景

遥感引导会跨越项目列表、项目详情和地块详情三个页面。旧实现使用固定延时和递归跳步寻找 DOM，页面切换、数据加载、用户返回或目标不存在时容易出现步骤错位；桌面端把列表容器当作地块目标时，点击筛选也可能误推进引导。

## 决策

引导控制器统一负责步骤迁移：

- 每个步骤记录进入该步骤时的内部路径，前进和返回都使用同一份路径记录。
- 进入步骤时先按需导航，再轮询真实目标；每次新的步骤迁移都会取消上一次等待。
- 页面准备事件保留重试发送，但限制发送频率，兼顾跨页面挂载时序和渲染开销。
- 目标在等待窗口内不可用时显示“重试/跳过”，不再静默跳到后续步骤。
- 地块步骤只定位带有 `data-tour-href` 的地块按钮，不定位列表容器。
- 引导存储键升级到 `v3`，让已完成旧流程的账号重新体验新流程。

## 影响

- 引导可以在页面加载慢、无项目或目标暂时缺失时安全降级。
- 用户点击真实目标即可继续，普通链接不会被重复 `router.push`；组合键打开新窗口不会改变当前引导。
- 新增的“不可用/重试”提示需要在所有支持语言中维护对应文案。
